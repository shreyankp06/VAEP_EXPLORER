PROJECT BACKGROUND
------------------------------------------------------

The project is inspired by the research paper

"Actions Speak Louder than Goals: Valuing Player Actions in Soccer"

(KDD 2019)

The project DOES NOT aim to reproduce or retrain the original machine learning model.

Instead, it uses precomputed SPADL and VAEP data to build an interactive educational visualization platform.

The objective is to help users understand why different player actions have different values through visual exploration.

The application should be treated as a modern analytics dashboard rather than a machine learning research project.
